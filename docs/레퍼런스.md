# 레퍼런스 — flex · Frappe HR · Odoo에서 참고할 기능 3가지

작성일: 2026-09-14 · 참고 대상: 가온교육 인사·총무 근태 앱 (직원 · 근태 · 휴가 · 집계)

| # | 제품 | 참고할 기능·화면 | 우리 앱에 넣을 자리 |
|---|---|---|---|
| 1 | flex (한국) | 휴가 보유 현황 + 휴가 조정(사유 필수) + 휴가 히스토리 | 직원 상세 → "연차 히스토리" 표 |
| 2 | Frappe HR (오픈소스) | Monthly Attendance Sheet — 직원 × 날짜 격자 리포트 | 집계 탭 → "일자별 보기" |
| 3 | Odoo (오픈소스) | Time Off Overview — 팀 휴가 캘린더 (상태별 색·무늬) | 휴가 탭 → "팀 캘린더" |

## 1. flex — 휴가 보유 현황 · 휴가 조정 · 휴가 히스토리

**무엇인가**
- "현재 기준으로 보유한 구성원의 휴가 현황"을 구성원별로 조회하는 화면.
- 연차를 추가·차감하는 **휴가 조정**은 조정 적용일 · 대상자 · 조정 값 · **조정 사유(필수)** 를 입력해야 적용됨.
- **히스토리**에서 선택한 기간의 부여 · 차감 · 소멸 · 잔여 내역을 한 번에 확인. 미래 날짜로 조회하면 발생 예정 연차도 미리 볼 수 있음.

**왜 참고하나**
- 우리 앱은 "남은 연차 = 부여 − 승인된 사용"을 매번 계산해 숫자 하나만 보여줌. 담당자가 실제로 받는 질문은 "왜 13.5일이에요?"이므로, **숫자가 만들어진 과정(부여 → 사용 → 조정)** 을 한 표로 보여주는 히스토리가 교육에 더 효과적.
- "조정 사유 필수"는 인사 데이터를 손으로 고칠 때 근거를 남기는 실무 습관을 가르치기 좋음 (감사 대응).
- 한국 연차 규칙(1년 미만 월 1일, 이후 15일, 근속 가산)을 그대로 쓰는 국내 서비스라 용어·흐름이 우리 앱과 맞음.

**반영 방법 (제안)**
- 직원 상세 아래에 "연차 히스토리" 표 추가: 날짜 · 구분(부여/사용/조정) · +/− 일수 · 잔여 · 사유·근거(신청번호).
- 연차 관리에 "조정" 버튼(일수 + 사유 필수)을 두고, 조정 내역도 히스토리에 쌓이게 함.

**출처 (공식 헬프센터)**
- 휴가 보유 현황 및 휴가 조정하기: https://guide.flex.team/ko/articles/10288667
- flex 웹에서 휴가 등록 및 내 휴가 관리하기 (잔여 수량·승인 상태·사용 기한 표시): https://guide.flex.team/ko/articles/10229315
- flex 근태 관리 소개 (근무 유형·휴가 정책): https://flex.team/landing/service/time-tracking

## 2. Frappe HR — Monthly Attendance Sheet (월간 근태표)

**무엇인가**
- 직원별 출석 상태를 **직원 × 날짜 격자**로 보여주는 표준 리포트. 각 칸에 출근(P) · 결근(A) · 휴가(L) · 반일(HD) 등의 기호가 찍히고, 오른쪽에 합계가 붙음.
- 부서 · 지점 · 직급별로 묶어 볼 수 있고, 일자별 칸을 숨기고 합계만 보는 "요약 보기"도 있음.
- 근태(Attendance) 자체는 하루 단위 기록이며 상태는 Present / Absent / On Leave / Half Day. 체크인 로그로 자동 생성하거나, Employee Attendance Tool로 여러 명을 한 번에 표시할 수 있음. 미래 날짜는 기록할 수 없음.

**왜 참고하나**
- 우리 집계 탭은 직원별 **합계**만 보여줌. 담당자가 실무에서 보는 건 "이 사람이 며칠에 지각했지?"이므로, 합계가 **어느 날짜에서 나왔는지** 보이는 격자가 있어야 집계 숫자를 신뢰하고 검증하는 습관이 생김.
- 우리 데이터(24명 × 20근무일)는 격자로 그리기 딱 좋은 크기.
- "미래 날짜 기록 불가", "여러 명 한 번에 확정" 같은 규칙은 우리 근태 탭의 "미확정 건 규칙대로 채우기"와 같은 발상이라 설명하기 쉬움.

**반영 방법 (제안)**
- 집계 탭에 "합계 보기 / 일자별 보기" 전환 추가. 일자별 보기는 열 = 날짜(주말·공휴일은 회색), 칸 = 정상 ○ · 지각 △ · 조퇴 ▽ · 결근 × · 휴가 休 · 반차 半 · 미확정 공백, 아래에 범례.
- 칸을 누르면 근태 탭의 그 날짜·그 직원 줄로 이동 ("이 위치 보기"와 같은 방식).

**출처 (공식 문서)**
- Human Resources Reports (Monthly Attendance Sheet 설명): https://docs.frappe.io/hr/human-resources-reports
- Attendance (상태 종류, 자동 생성, Attendance Tool): https://docs.frappe.io/hr/attendance
- Leave Application (신청 전 잔여일 표시, 공휴일·차단일 검증, 승인 흐름) — 휴가 탭 보강 시 참고: https://docs.frappe.io/hr/leave-application

## 3. Odoo — Time Off Overview (팀 휴가 캘린더)

**무엇인가**
- Time Off 앱 › Overview: 본인 또는 **관리하는 팀의 휴가를 색으로 표시한 캘린더**. 기본 필터는 My Team, 기본 보기는 분기(3개월).
- 상태를 무늬로 구분: **승인 = 단색, 승인 대기 = 흰 줄무늬, 거절 = 취소선**. 공휴일도 캘린더에 함께 표시.
- 대시보드 옆 잔여 카드에는 휴가 유형별로 "할당 · 누적 예정 · 승인된 휴가 · 계획된 휴가 · 현재 사용 가능"이 나뉘어 보이고, "특정 날짜 기준 잔액"도 볼 수 있음.
- 관리 화면(All Time Off)은 기본 필터가 "내게 대기 중"이라 승인할 건만 먼저 보이고, 부서별로 묶어 승인/거절 버튼으로 바로 처리.

**왜 참고하나**
- 우리 앱의 핵심 규칙 "**같은 팀 같은 날 2명 이상 연차 불가**"를 지금은 표의 경고 글자로만 알려줌. 캘린더에 팀원 휴가를 겹쳐 보여주면 **왜 R-035를 반려해야 하는지 눈으로** 바로 이해됨.
- "대기 = 줄무늬"처럼 아직 확정 안 된 것을 시각적으로 구분하는 방식은 우리 근태 탭의 "미확정"에도 그대로 쓸 수 있음.
- "내게 대기 중" 기본 필터는 우리 휴가 탭이 대기 건을 맨 위에 두는 것과 같은 의도 — 담당자가 할 일부터 보이게.

**반영 방법 (제안)**
- 휴가 탭 위에 "팀 캘린더" 추가: 부서 선택 → 해당 달의 날짜 × 팀원 격자. 승인은 단색, 대기는 줄무늬, 반려는 취소선. 같은 날 2명 이상이면 그 날짜 열을 노랗게 강조.
- 따라해보기 ④에 "팀 캘린더에서 9/21 열이 노랗게 표시된 것을 확인" 단계 추가.

**출처 (공식 문서, Odoo 18.0)**
- My time — Dashboard / Overview (캘린더, 상태별 표시, 잔여 카드): https://www.odoo.com/documentation/18.0/applications/hr/time_off/my_time.html
- Management — All Time Off (기본 필터 "내게 대기 중", 승인/거절): https://www.odoo.com/documentation/18.0/applications/hr/time_off/management.html
- Time Off 개요 (휴가 유형·누적 계획·공휴일 설정): https://www.odoo.com/documentation/18.0/applications/hr/time_off.html
- Attendances (Overview 간트/리스트, "Errors" 필터 = 체크아웃 누락, 지각·조퇴 허용 시간) — 근태 탭 보강 시 참고: https://www.odoo.com/documentation/18.0/applications/hr/attendances.html
