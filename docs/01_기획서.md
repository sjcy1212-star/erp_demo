# 인사·총무 교육용 가상 업무 앱 — 기획서 (v0.3)

> **v0.3 변경 (2026-09-14)**: 교육 방식을 "미션·퀴즈형"에서 **seolcoding.com/erp 형식(설명 + 따라해보기 시나리오 + 탭 화면)**으로 바꿈.
> 미션 패널·정답 입력·완료 판정은 없애고, 대신 "이 앱은 무엇인가요?" 4칸 설명, 따라해보기 6가지 시나리오(이 위치 보기 버튼), 탭 4개(직원·근태·휴가·집계), ? 설명 보기, 가상 데이터 초기화로 구성.
> 아래 6~8절의 "미션" 표는 시나리오 설계의 바탕으로 남겨 둠.

작성일: 2026-09-14

---

## 1. 한 줄 정의

> 처음 인사 업무를 맡는 담당자가 **근태·휴가 업무를 미션을 풀며 익히는** 브라우저 연습용 앱

## 2. 누가, 왜 쓰나

| 항목 | 내용 |
|---|---|
| 교육 대상 | 인사·총무를 처음 맡는 신입 담당자, 다른 부서에서 전환된 담당자 |
| 배우는 것 | 출퇴근 기록 관리, 연차 계산, 휴가 신청·승인 흐름, 월간 근태 마감 |
| 쓰는 방법 | 파일을 더블클릭해 브라우저에서 열고, 왼쪽 미션 목록을 순서대로 수행 |
| 걸리는 시간 | 미션 8개 기준 약 1~2시간 |

## 3. 업무 범위 (이번 버전)

**포함:** 근태(출퇴근 기록·지각·조퇴·결근), 휴가(연차·반차·병가·경조휴가), 연차 잔여일 계산, 월간 근태 집계

**제외 (다음 버전 후보):** 급여 계산, 입·퇴사 처리, 비품·시설 관리

## 4. 가상 회사 설정

- 회사명: **㈜가온교육 (가상)** — 화면 곳곳에 "(가상)" 표시
- 규모: 직원 24명, 4개 부서 (경영지원팀·개발팀·영업팀·디자인팀)
- 근무 시간: 09:00~18:00 (점심 12:00~13:00), 주 5일
- 인물 이름: 실존 인물과 겹치지 않도록 성 + 두 글자로 자동 생성 (예: 가나다, 마바사 식이 아닌 자연스럽지만 흔치 않은 조합)
- 사번: E-1001 ~ E-1024
- 기준일: 앱을 여는 "오늘"이 아니라 **가상의 오늘 = 2026-09-14** 로 고정 (교육 결과가 매번 같도록)

## 5. 교육용 표시 원칙 (중요)

1. 모든 화면 맨 위에 노란 띠로 **"⚠ 교육용 가상 자료 — 실제 인물·회사와 무관"** 고정 표시
2. 모든 파일(코드·문서·데이터) 첫 줄에 같은 문구 주석
3. 회사명 뒤에 항상 **(가상)** 붙임
4. 인쇄·내보내기 결과물에도 상단 문구 포함

## 8. 연차 계산 규칙 (교육용으로 단순화)

> 실제 법령·회사 규정은 더 복잡합니다. 교육용으로 핵심만 남겼습니다.

- 입사 1년 미만: 한 달 개근할 때마다 1일 (최대 11일)
- 입사 1년 이상: 15일
- 3년차부터 2년마다 1일 추가, 최대 25일
- 반차 = 0.5일 차감
- 병가·경조휴가는 연차에서 차감하지 않음
- **팀 규정**: 같은 팀에서 같은 날 2명 이상 연차 사용 불가 (미션 6에서 사용)

## 9. 기술 방식 (코딩 몰라도 되는 부분)

- **HTML + CSS + JavaScript 파일 몇 개**로 만들고, `index.html` 더블클릭이면 실행
- 서버·설치·로그인 없음
- 입력한 데이터는 **브라우저 안에만 저장** (다른 사람 컴퓨터에는 안 감)
- "처음 상태로 되돌리기" 버튼으로 언제든 초기화 → 여러 명이 같은 컴퓨터로 반복 연습 가능
