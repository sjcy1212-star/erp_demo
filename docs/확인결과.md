## 2. 발견한 오작동과 수정 내용

### 오작동 1 — 등록·저장이 거부되면 입력한 값이 지워짐 (#9, #12)

- **현상**: 휴가 등록 폼에서 날짜를 거꾸로 넣고 등록하면 안내는 맞게 뜨지만 폼이 다시 그려지면서 직원·날짜·사유가 모두 초기값으로 돌아감. 급여 입력 폼도 공제를 잘못 넣으면 저장된 값으로 되돌아감. 사용자는 오타 하나 고치려고 전부 다시 입력해야 함.
- **원인**: 화면을 다시 그릴 때 폼을 항상 기본값으로 만들었음.
- **수정** (`erp_small/app.js`): 입력값을 임시로 기억하는 `leaveDraft`·`payDraft`를 두고, 등록/저장을 누르는 순간 값을 기억 → 오류면 그 값으로 다시 그림, 성공하면 비움. 직원·지급월을 바꾸면 급여 폼은 그 건의 금액을 새로 불러옴(기존 동작 유지).
- **재확인**: 같은 조작 반복 → 직원 H-008 / 2026-10-20 / 2026-10-15 / "날짜 거꾸로"가 그대로 남음(캡처 09). 종료일만 10-21로 고쳐 등록 → L-008 2일 등록 성공, 폼 비워짐. 급여 공제 9999999도 유지됨(캡처 10).

### 오작동 2 — 표 안 설명 말풍선이 잘림 (#14)

- **현상**: 설명 모드에서 표 머리글의 말풍선이 표 상자 경계에 잘려 두 줄째가 안 보이고, 표 안에 가로·세로 스크롤바가 생김.
- **원인**: 말풍선을 머리글 요소의 `::after`로 그렸는데, 표 상자가 `overflow: auto`라 상자 밖으로 나가는 부분이 잘림.
- **수정** (`erp_small/app.js`, `style.css`): 말풍선을 화면에 하나(`#helpTip`, `position: fixed`)만 두고 마우스를 올린 요소의 위치를 재서 그 아래에 붙임. 오른쪽·아래로 넘치면 자동으로 안쪽으로 옮김. 터치 기기는 누르면 뜨고, 스크롤하면 숨김.
- **재확인**: 같은 머리글에 마우스 올림 → "그 달 모든 건의 실지급액을 더한 값. 저장하지 않고 볼 때마다 계산합니다." 두 줄이 통째로 보이고 스크롤바 없음(캡처 13).

### 재발 방지

`tests/check.js`에 검사 2개 추가: **폼유지**(오류 뒤 입력값 유지), **말풍선**(설명 모드에서 표 머리글 말풍선이 화면 위에 보임). 총 17개, 모두 통과.

- **방법**: 이 PC에 설치된 Chrome을 명령줄(헤드리스)로 띄워 `file:///C:/Users/USER/Desktop/erp_demo/erp_small/index.html?test=1` 을 직접 열고, 실행이 끝난 화면(DOM)을 저장. (Playwright 도구는 file:// 접근이 막혀 있어 이 방법을 씀)
- **결과**: **자동 검사 17 / 17 통과** — 서버 없이 더블클릭 방식으로 열어도 데이터 읽기(`data/가상_인사총무.js`), 저장(localStorage), 새로고침 유지, 모든 규칙이 동일하게 동작.
