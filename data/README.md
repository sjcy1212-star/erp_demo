## 각 데이터의 칸 설명

**employees (직원)**: `id` 사번, `name` 이름, `dept` 부서, `position` 직급, `hireDate` 입사일

**attendance (출퇴근)**: `date` 날짜, `empId` 사번, `checkIn` 출근시각, `checkOut` 퇴근시각, `status` 상태(정상/지각/조퇴/결근/휴가/반차/미확정), `note` 비고

**leaves (휴가)**: `id` 접수번호, `empId`/`empName`/`dept`, `type` 종류(연차/반차/병가/경조휴가), `start`~`end` 기간, `days` 일수, `deduct` 연차 차감 일수, `status` 상태(승인/대기/반려), `reason` 사유, `requestedAt` 신청일, `decidedAt` 처리일, `decisionNote` 처리 메모

**leaveSummary (연차 요약)**: `entitled` 부여, `used` 사용, `remaining` 잔여, `months` 근속 개월

**missionKeys (미션 정답표)**: 앱이 미션 완료를 자동 판정할 때 사용
